
# Day 01 — Software Engineering Mindset

## Main concept
Software engineering is more than writing code. It includes understanding requirements, designing solutions, testing, delivery, and maintenance.

## What I learned
- Coding vs programming vs software engineering
- Functional and non-functional requirements
- Acceptance criteria
- Reproduce, investigate, fix, and verify a bug

## Explain it in my own words
- Coding means writing instructions in a programming language.Software engineering includes understanding requirements, designing solutions, writing and designing code, deploying it and maintaining it overtime.

## Practical example
Feature: User login

Acceptance criteria:
- Valid credentials allow authorized access.
- Invalid credentials produce an appropriate error.
- Network failures are handled without falsely logging in the user.

## Edge cases
- The server become unavailabe during login. The application should display an appropriate message, preserve the user's ability to retry also.
